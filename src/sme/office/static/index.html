BRING YOUR ENGINE TO WORK

Hubungkan kantor ke PULSE.

Dashboard ini sudah satu paket dengan PULSE. Saat dijalankan lewat python run.py, kantor otomatis mengikuti aktivitas engine dan status chain dari konfigurasi yang ada.

Cara menjalankan paket gabungan

Dari folder PULSE, gunakan environment Python engine yang dependensinya sudah terpasang:

python run.py

Buka http://127.0.0.1:8765. Mode live terhubung otomatis. Untuk melihat kantor tanpa menjalankan engine:

python run.py --demo

Konfigurasi chain dan kredensial tetap di .env lokal. Klik mode demo di sini hanya mengubah tampilan; engine tetap berjalan sampai dihentikan dengan Ctrl+C di terminal.
